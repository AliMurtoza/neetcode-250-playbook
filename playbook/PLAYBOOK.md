# Algorithmic Playbook

The `playbook/` directory contains the higher-level algorithmic knowledge extracted from solving the NeetCode 250.

The individual problem directories document specific problems.

The playbook documents the patterns connecting those problems.

## Purpose

The goal is to move from:

> "I know how to solve this problem."

to:

> "I recognize this type of problem and know which techniques to consider."

The playbook is therefore focused on **transferable problem-solving knowledge**.

## What Will Be Documented?

Playbook entries may cover:

- Algorithmic patterns
- Data structure patterns
- Recognition signals
- Common approaches
- Variations
- Common mistakes
- Complexity considerations
- Representative problems
- Lessons learned across multiple problems

## Core Idea

Individual problems are examples.

The playbook is the knowledge extracted from those examples.

        ↓
